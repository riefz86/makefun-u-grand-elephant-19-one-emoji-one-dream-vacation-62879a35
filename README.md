Entry for the [make.fun](https://make.fun) bounty **One Emoji, One Dream Vacation** — one emoji, nothing else, standing in for the trip of my dreams.

## The entry

🌅 — a sunrise over the sea. The first morning of a dream trip: sun, sea, a faraway shore, in a single glance. No words, no second emoji.

`main.py` writes exactly that one emoji to `/output/entry.txt` (UTF-8, 1 character, 4 bytes), deterministically, and leaves the file world-readable.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
